# Звички

Особистий Android-трекер звичок. Kotlin + Jetpack Compose. Усі дані зберігаються лише на пристрої, застосунок не має доступу до мережі.

## Що вміє

- Три типи звичок: відмітка, число за день, запис із власними полями (для пробіжки: дистанція, час, темп рахується сам).
- Розклад: щодня, конкретні дні тижня, N разів на тиждень, кожні N днів.
- Пропуск дня без втрати серії та «сила звички», яку один промах знижує, а не обнуляє.
- Нагадування зі сповіщенням і кнопками «Зроблено», «Через годину», «Пропустити».
- Статистика: теплова карта за 16 тижнів, серії, останні записи; будь-який минулий день можна виправити.
- Резервна копія у файл (JSON), експорт у CSV.

## Збірка

Кожен пуш у `main` запускає GitHub Actions: збирається APK і публікується в розділі Releases. Лог останньої збірки лежить у гілці `ci-logs`.

Локально: `gradle :app:assembleRelease` (Gradle 8.9, JDK 17, Android SDK 35).

## Підпис

APK підписується ключем із `keystore/habits.jks`, який лежить у репозиторії, щоб кожна нова збірка встановлювалась поверх попередньої без втрати даних. Це прийнятно для особистого застосунку, який ставиться вручну; для публікації в магазині потрібен окремий приватний ключ.
